Payment Protocol

x402: Pay-Before-Response

The x402 standard enables seamless machine-to-machine payments. AI agents can programmatically send and receive on-chain micropayments with a single line of code — no intermediaries required.

  • One-line payment integration
  • TRON & BNB Chain support
  • Machine-to-machine optimized
  • More chains coming soon
payment.ts 
import { payWithx402 } from '@bankofai/x402';

// One-line payment
const receipt = await payWithx402({
  to: 'TAgent...xyz',
  amount: '10.00',
  token: 'USDT',
  chain: 'tron'
});

console.log(receipt.txHash);
// → "a1b2c3...f4e5d6"
Identity Standard

8004: On-chain AI Identity

Give your AI agents a verifiable on-chain identity. The 8004 standard mints agent identities as NFTs with built-in reputation scoring, enabling trustworthy machine-to-machine interactions.

  • Identity as NFT
  • Built-in reputation system
  • Cross-chain compatible
  • Verifiable agent credentials
identity.ts 
import { AgentID } from '@bankofai/8004';

const agent = await AgentID.register({
  name: 'TradingBot-01',
  chain: 'tron',
  capabilities: [
    'swap', 'lend', 'transfer'
  ]
});

// Check reputation
const rep = await agent.getReputation();
// → { score: 95, txCount: 1240 }

Quick Integration

Drop-in OpenClaw Extension

Give any OpenClaw agent full banking capabilities with a single extension. Payments, identities, and DeFi — no additional setup required.

Instant Setup

Add the extension and your agent is ready to transact on-chain.

Full Banking Suite

Access payments, identity, and DeFi through a unified API.

Multi-chain Ready

Works across TRON and BNB Chain with more chains coming.

agent.config.ts 
import { OpenClaw } from 'openclaw';
import { BankOfAI } from '@bankofai/openclaw';

const agent = new OpenClaw({
  extensions: [
    BankOfAI({
      chains: ['tron', 'bnb'],
      features: {
        payments: true,
        identity: true,
        defi: true
      }
    })
  ]
});

// Agent is ready to bank!
await agent.start();
