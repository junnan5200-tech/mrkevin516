# Bank of AI Website

The official website for **Bank of AI** — The Financial Infrastructure for AI Agents.

## Overview

On-chain payments, identities, and DeFi purpose-built for autonomous AI agents. Starting with TRON & BNB Chain, expanding to all chains.

## Project Structure

```
├── index.html          # Main HTML page
├── css/
│   └── style.css       # Styles with CSS custom properties, animations, responsive design
├── js/
│   └── main.js         # Interactions: scroll animations, counters, mobile nav, search
├── package.json        # Project metadata
└── README.md
```

## Getting Started

This is a static website. To run locally:

```bash
# Using npx serve
npx serve .

# Or simply open index.html in a browser
open index.html
```

## Design Principles

- **Clear value proposition** — the hero title immediately communicates what the product does
- **Single primary CTA** — the AI search box is the main interaction point
- **Natural reading flow** — title → subtitle → search → secondary actions → social proof
- **Unified color system** — consistent purple brand palette with intentional accent colors
- **Chain brand parity** — TRON and BNB Chain are displayed with equal visual weight
- **Accessibility** — proper contrast ratios, semantic HTML, ARIA labels
- **Performance** — no heavy frameworks, CSS animations, progressive enhancement
